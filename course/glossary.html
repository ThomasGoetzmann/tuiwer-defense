Glossary

Each Rust term has one meaning in this course. The C# column gives the nearest idea. “Nearest” does not mean “the same”: read the notes.

Rust termNearest C# ideaMeaning in this course
associated functionstatic methodA function in an impl block without self. Call it with Type::name(). new is a convention, not a keyword.
borrow(none)To use a value through a reference, without taking ownership. &T is a shared borrow. &mut T is an exclusive borrow.
borrow checker(none)The part of the compiler that proves all borrows are valid. It runs at compile time only.
cargodotnet CLI + NuGetThe build tool and package manager. It builds, tests, runs and adds dependencies.
clippyRoslyn analyzersA linter with hundreds of checks. Run it with cargo clippy.
CloneICloneable (but typed)A trait for an explicit copy: value.clone(). It can be expensive.
Copyvalue-type assignmentA trait for small values that copy implicitly on assignment, like u32 or a small struct.
crateassembly / projectOne unit of compilation: a library or a binary.
derivesource generator#[derive(Debug, Clone)] makes the compiler write a trait implementation for you.
editionLangVersionA set of language rules. This course uses edition 2024. Crates of different editions work together.
enumF# discriminated unionA type that is one of several variants. Each variant can hold data. Much more than a C# enum.
expressionexpressionCode that gives a value. In Rust, if, match and blocks are expressions.
impl blockclass bodyThe place where you write methods for a type. A type can have many impl blocks.
lifetime(none)The region of code where a reference is valid. Written 'a. Chapter 10.
macrosource generator (loosely)Code that writes code at compile time. Its name ends with !, for example println!.
methodinstance methodA function in an impl block whose first parameter is self, &self or &mut self.
move(none)To give ownership of a value to another variable or function. After a move, the old variable is not usable.
newtypesingle-field record structA tuple struct that wraps one value, like struct Gold(u32). It stops you mixing up values of the same raw type.
Option<T>T? (nullable)A value that is Some(value) or None. Rust has no null. Chapter 4.
ownership(the GC, inverted)Each value has exactly one owner. When the owner goes out of scope, the value is dropped. Chapter 3.
package.csprojA folder with a Cargo.toml. It contains one or more crates.
panicunhandled exceptionA crash for bugs, not for expected errors. Expected errors use Result.
Result<T, E>exceptions / TryParseA value that is Ok(value) or Err(error). Chapter 4.
rust-analyzerRoslyn language serverThe language server. It gives completion, errors and refactors in your editor.
rustfmtdotnet formatThe standard formatter. Everybody uses the same style.
rustup.NET SDK installer + global.jsonThe tool that installs and updates Rust toolchains.
shadowing(none)Declaring a new variable with the same name as an old one: let x = x + 1;. The old one is hidden.
sliceSpan<T> / ReadOnlySpan<T>A borrowed view into a sequence: &[T] or &str.
statementstatementCode that does not give a value. A ; turns an expression into a statement.
&strReadOnlySpan<char>A borrowed string slice. String literals are &'static str.
StringStringBuilder (owned, growable)An owned, growable UTF-8 string on the heap.
structstruct / record structA type with named fields. No inheritance. Stored inline, not behind a reference.
toolchainan SDK versionOne version of rustc, cargo and the other tools, installed by rustup.
traitinterfaceA set of methods a type can implement. Traits can be implemented for types you do not own. Chapter 6.
unit type ()voidThe type with one value, (). Functions without a return type return it. Unlike void, it is a real value.
usizenint (unsigned)An unsigned integer with the size of a pointer. Used for indexes and lengths.
Vec<T>List<T>A growable array on the heap.
workspace.slnA group of packages that share one Cargo.lock and one target/ folder.

The glossary grows with each chapter.
