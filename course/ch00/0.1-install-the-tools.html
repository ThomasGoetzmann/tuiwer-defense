Concept

One installer, many tools

rustup installs a toolchain: one version of the compiler and all its tools. All tools in a toolchain have the same version. This prevents mismatch problems.

Hands-on

Install and check

  1. Update your toolchain. Then add the components that editors need.

    rustup update stable
rustup component add rust-analyzer rust-src clippy rustfmt
rustup component list --installed

    Make sure the list contains rust-analyzer and rust-src. (Your chezmoi script does the same on a new machine.)

  2. Look at what you have:

    rustup show
which cargo rustc rust-analyzer

    All three paths must be in ~/.cargo/bin. These files are small proxies. They start the correct tool from the active toolchain.

  3. Install JetBrains Toolbox with Homebrew. Then start it once.

    brew install --cask jetbrains-toolbox
jetbrains-toolbox &

    In Toolbox, find RustRover and click Install. RustRover is free for non-commercial use. Choose the non-commercial licence on the first start.

  4. Start RustRover. Open Settings → Languages & Frameworks → Rust. Make sure the Toolchain location is ~/.cargo/bin and the Standard library field is filled. If it is empty, click Download via rustup.

  5. Optional: set up Neovim now. Follow Appendix A. The changes are already in your dotfiles. You only apply and test them.

  6. Open the Rust book and the standard library docs, offline:

    rustup doc --book
rustup doc --std

    Bookmark both pages. Chapters 1 to 3 of the book follow the same order as this course.

Check 
rustc --version; and cargo --version; and rust-analyzer --version; and cargo clippy --version

All four commands print a version. RustRover shows no warning about the toolchain.

Why Rust does this

Rust releases a new stable version every six weeks. A new version never breaks old code that compiles. Large changes come only in editions (2015, 2018, 2021, 2024), and each crate chooses its edition. So updates are cheap: you run rustup update and continue. This is why the Rust community does not fear updates, unlike many .NET major-version migrations.

Deep dive

You can pin a toolchain for one project with a rust-toolchain.toml file, like global.json. You can also install the nightly toolchain for experimental features: rustup toolchain install nightly. This course uses stable only.
